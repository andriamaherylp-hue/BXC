# Intégration images.rar — 20/08/2026

Cette version contient les 28 fichiers originaux de `images.rar` dans :

- `frontend/public/bxc-winrar-original/`
- `frontend/src/assets/bxc/winrar/`

Les logos correspondants sont reliés à l'interface Market (cartes, tableau et page détail) pour BTC, DOGE, DOT, XLM, UNI, GBP/USD, EUR/USD, USD/HKD, USD/CNY, CAD/USD, TSLA, GOOGL, MSFT, ORCL, JPM, JNJ, PLTR, PG, XNG, XAL, XCU, XPD, XPT, XNI, XPB et XZN.

`EURUSD.png` et `GBPHKD.png` sont également inclus intégralement comme fichiers source originaux. `EURUSDD.png` est utilisé pour EUR/USD car il correspond au visuel EUR/US fourni. `GBPHKD.png` n'est pas affiché car la liste actuelle des marchés BXC ne contient pas de ligne GBP/HKD.

Le favicon du navigateur utilise maintenant le logo BXC (`frontend/public/favicon-bxc.png`).

L'archive originale est également conservée dans `reference_images/source_archives/images.rar`.
Le très long nom du fichier source BXC AVIF a été raccourci en `frontend/public/bxc-source-images/bxc-logo-source.avif` pour réduire les problèmes de chemins longs sous Windows.
